# Section XIII: Measure Theory & Advanced Probability — Detailed Problem List

> *Foundation: σ-algebras, Lebesgue integration, Radon-Nikodym theorem*

Measure theory provides the rigorous mathematical foundation for all of probability and stochastic calculus. While many quant interviews stay at the "applied" level, top-tier firms (especially in derivatives pricing and research) expect fluency with σ-algebras, changes of measure, and the fundamental theorems of asset pricing. These are the concepts that make risk-neutral pricing, Girsanov's theorem, and martingale representation "work" beneath the surface.

---

## 1. Probability Spaces & σ-Algebras

### Core Concepts

- **Probability Space:** A triple $(\Omega, \mathcal{F}, P)$ where $\Omega$ is the sample space, $\mathcal{F}$ is a σ-algebra of events, and $P$ is a probability measure with $P(\Omega) = 1$.
- **σ-Algebra:** A collection $\mathcal{F}$ of subsets of $\Omega$ closed under complementation and countable unions. Contains $\emptyset$ and $\Omega$. Represents the "information" available.
- **Filtration:** An increasing sequence of σ-algebras $\mathcal{F}_0 \subseteq \mathcal{F}_1 \subseteq \cdots \subseteq \mathcal{F}_T$. Represents information accumulating over time. A process is adapted to a filtration if $X_t$ is $\mathcal{F}_t$-measurable for all $t$.
- **Measurable Function / Random Variable:** A function $X: \Omega \to \mathbb{R}$ such that $\{X \le a\} \in \mathcal{F}$ for all $a$. This ensures probabilities of events involving $X$ are well-defined.
- **Borel σ-Algebra:** The σ-algebra generated by open sets in $\mathbb{R}$. Contains all intervals, countable unions/intersections of intervals, etc. The "standard" σ-algebra on $\mathbb{R}$.
- **Generated σ-Algebra:** $\sigma(X)$ is the smallest σ-algebra making $X$ measurable. Represents "the information contained in $X$."

### Key Problems and Questions

- **Constructing σ-Algebras:** Let $\Omega = \{1, 2, 3, 4\}$. List all possible σ-algebras on $\Omega$. How many are there? For a partition $\{\{1,2\}, \{3,4\}\}$, write the generated σ-algebra. What events can you distinguish?
- **Filtration — Coin Flips:** Two coins are flipped. $\Omega = \{HH, HT, TH, TT\}$. Define $\mathcal{F}_0 = \{\emptyset, \Omega\}$ (no information), $\mathcal{F}_1 = \sigma(\text{first flip})$, $\mathcal{F}_2 = 2^\Omega$ (full information). Write out each σ-algebra explicitly. Show the filtration is increasing.
- **Measurability — What Can You Compute?** Given $\mathcal{F}_1 = \sigma(\text{first flip})$ above, which of the following are $\mathcal{F}_1$-measurable? (a) "First coin is H," (b) "Both coins are H," (c) "At least one H." Explain why measurability represents "knowability given the available information."
- **σ-Algebra Generated by a Random Variable:** $X: \Omega \to \mathbb{R}$ takes values $\{1, 2, 3\}$ on $\Omega = \{a, b, c, d, e\}$ with $X(a) = X(b) = 1$, $X(c) = X(d) = 2$, $X(e) = 3$. Compute $\sigma(X)$. Show it partitions $\Omega$ into the level sets of $X$.
- **Conditional Expectation as a Projection:** $E[X | \mathcal{G}]$ is the $\mathcal{G}$-measurable random variable that is the "best approximation" of $X$ given the information in $\mathcal{G}$. Compute $E[X | \mathcal{F}_1]$ for the two-coin example where $X = $ number of heads. Verify the tower property $E[E[X|\mathcal{F}_1]] = E[X]$.
- **Why Do We Need σ-Algebras?** Construct a non-measurable set (Vitali set) on $[0,1]$ using the axiom of choice. Show that assigning a "length" (Lebesgue measure) to it leads to a contradiction. This is why we restrict to measurable sets.
- **Product σ-Algebra:** For two experiments modeled on $(\Omega_1, \mathcal{F}_1)$ and $(\Omega_2, \mathcal{F}_2)$, the joint experiment lives on $\Omega_1 \times \Omega_2$ with σ-algebra $\mathcal{F}_1 \otimes \mathcal{F}_2$. Define this for two coin flips. Show it equals the power set for finite $\Omega$.
- **Tail σ-Algebra and Kolmogorov's 0-1 Law:** For i.i.d. random variables $X_1, X_2, \ldots$, the tail σ-algebra $\mathcal{T} = \bigcap_n \sigma(X_{n+1}, X_{n+2}, \ldots)$ contains events that don't depend on any finite number of $X_i$'s. Kolmogorov's 0-1 law: every event in $\mathcal{T}$ has probability 0 or 1. Apply: $P(\sum X_i \text{ converges}) \in \{0, 1\}$.
- **Information and Pricing:** In a one-period binomial model, the σ-algebra $\mathcal{F}_0 = \{\emptyset, \Omega\}$ represents the initial information (you know nothing about the stock's move). After the move, $\mathcal{F}_1 = 2^\Omega$. The option price at time 0 must be $\mathcal{F}_0$-measurable (a constant). At time 1, the payoff is $\mathcal{F}_1$-measurable. Relate this to the replicating portfolio argument.
- **Atoms of a σ-Algebra:** An atom is a minimal non-empty element of a σ-algebra. For a finite σ-algebra, the atoms form a partition of $\Omega$. Compute the atoms for $\sigma(\text{first coin flip})$ in the two-coin example. Explain why conditional expectation is constant on atoms.

## 2. Lebesgue Integration & Measure

### Core Concepts

- **Lebesgue Measure:** The "natural" measure on $\mathbb{R}$: $\lambda([a,b]) = b - a$. Extends to measurable subsets of $\mathbb{R}$. Countably additive.
- **Lebesgue Integral:** $\int f \, d\mu$ defined for measurable functions $f$. Generalizes the Riemann integral: handles more functions (e.g., $\mathbf{1}_{\mathbb{Q}}$ is Lebesgue-integrable but not Riemann-integrable).
- **Expectation as Lebesgue Integral:** $E[X] = \int_\Omega X(\omega) \, dP(\omega)$. This unifies discrete ($\sum x_i p_i$) and continuous ($\int x f(x) dx$) expectations.
- **Monotone Convergence Theorem (MCT):** If $0 \le f_n \uparrow f$ pointwise, then $\int f_n \, d\mu \uparrow \int f \, d\mu$. Allows interchanging limits and integrals for increasing sequences.
- **Dominated Convergence Theorem (DCT):** If $f_n \to f$ pointwise and $|f_n| \le g$ with $\int g < \infty$, then $\int f_n \to \int f$. The workhorse for interchanging limits and expectations.
- **Fatou's Lemma:** $\int \liminf f_n \le \liminf \int f_n$ for non-negative $f_n$. A one-sided inequality when DCT conditions aren't met.
- **$L^p$ Spaces:** $L^p = \{f : \int |f|^p \, d\mu < \infty\}$. $L^2$ is a Hilbert space (inner product $\langle f, g \rangle = \int fg$). Conditional expectation is the $L^2$ projection onto the subspace of $\mathcal{G}$-measurable functions.

### Key Problems and Questions

- **Lebesgue vs. Riemann — Dirichlet Function:** Let $f = \mathbf{1}_{\mathbb{Q} \cap [0,1]}$ (1 on rationals, 0 on irrationals). Show the Riemann integral doesn't exist (upper sum = 1, lower sum = 0). Show the Lebesgue integral is 0 ($\lambda(\mathbb{Q} \cap [0,1]) = 0$).
- **Expectation via Lebesgue Integral:** For a continuous r.v. with density $f(x)$, show $E[X] = \int x f(x) dx$ is a special case of $\int X \, dP$ where $dP = f(x) dx$. For a discrete r.v., show $E[X] = \sum x_i P(X = x_i)$ is the integral w.r.t. a counting measure.
- **MCT — Justifying Series Interchange:** Show $E[\sum_{n=1}^\infty X_n] = \sum_{n=1}^\infty E[X_n]$ for non-negative $X_n$ using MCT. Apply to prove $E[N_t] = \lambda t$ for a Poisson process by writing $N_t = \sum_{n=1}^\infty \mathbf{1}_{\{T_n \le t\}}$.
- **DCT — Differentiating Under the Integral:** Let $F(\theta) = E[g(X, \theta)] = \int g(x, \theta) f(x) dx$. Show $F'(\theta) = \int \frac{\partial g}{\partial \theta} f(x) dx$ using DCT (need $|\partial g / \partial \theta| \le h(x)$ integrable). Apply to computing Greeks: $\text{Vega} = \frac{\partial}{\partial \sigma} E^Q[\text{payoff}]$.
- **Fatou's Lemma — Why Limits and Expectations Don't Always Commute:** Construct a sequence $f_n$ where $f_n \to 0$ pointwise but $\int f_n = 1$ for all $n$. (E.g., $f_n = n \cdot \mathbf{1}_{[0, 1/n]}$.) Fatou's lemma gives $0 \le 1$, which is correct but not an equality. Relate to the failure of optional stopping for non-UI martingales.
- **$L^2$ Projection — Conditional Expectation:** Show that $E[X | \mathcal{G}]$ minimizes $E[(X - Y)^2]$ over all $\mathcal{G}$-measurable $Y$. This is the $L^2$ projection. Verify for $X = W_T$ and $\mathcal{G} = \sigma(W_t)$ with $t < T$: the best $L^2$ predictor of $W_T$ given $W_t$ is $W_t$ itself.
- **Uniform Integrability — Definition and Examples:** A family $\{X_\alpha\}$ is UI if $\sup_\alpha E[|X_\alpha| \mathbf{1}_{\{|X_\alpha| > M\}}] \to 0$ as $M \to \infty$. Show that a martingale bounded in $L^p$ ($p > 1$) is UI. Show the simple random walk $S_n$ is a martingale but not UI (hence OST fails for unbounded stopping times).
- **Convergence in $L^p$ vs. Almost Sure:** Construct a sequence that converges a.s. but not in $L^1$ (e.g., $X_n = n \cdot \mathbf{1}_{[0,1/n]}$). And one that converges in $L^1$ but not a.s. (typewriter sequence). These distinctions matter for limit theorems in finance.
- **Fubini's Theorem — Switching Order of Integration:** $\int\int f(x,y) \, dx \, dy = \int\int f(x,y) \, dy \, dx$ when $\int |f| < \infty$. Apply to computing $E[\int_0^T X_t \, dt] = \int_0^T E[X_t] \, dt$ for a stochastic process.
- **Radon-Nikodym as Density:** If $Q \ll P$ (Q is absolutely continuous w.r.t. P), then there exists $\frac{dQ}{dP} = L$ (the Radon-Nikodym derivative) such that $E^Q[X] = E^P[LX]$. Verify for $P = N(0,1)$ and $Q = N(\mu, 1)$: $L = e^{\mu x - \mu^2/2}$. This is the foundation of change-of-measure pricing.

## 3. Change of Measure & Girsanov's Theorem

### Core Concepts

- **Absolutely Continuous Measures:** $Q \ll P$ if $P(A) = 0 \Rightarrow Q(A) = 0$. Equivalent measures: $P \sim Q$ iff $P \ll Q$ and $Q \ll P$ (same null sets).
- **Radon-Nikodym Derivative:** $L = \frac{dQ}{dP}$ satisfies $E^Q[X] = E^P[LX]$. Converts expectations from one measure to another.
- **Girsanov's Theorem:** If $W_t$ is a BM under $P$ and $L_t = \exp(-\int_0^t \theta_s dW_s - \frac{1}{2}\int_0^t \theta_s^2 ds)$ defines a new measure $Q$ via $\frac{dQ}{dP}\big|_{\mathcal{F}_t} = L_t$, then $\tilde{W}_t = W_t + \int_0^t \theta_s ds$ is a BM under $Q$. In short: changing measure changes the drift.
- **Novikov's Condition:** $E^P[\exp(\frac{1}{2}\int_0^T \theta_s^2 ds)] < \infty$ guarantees $L_t$ is a true martingale (not just a local martingale), so $Q$ is a valid probability measure.
- **Risk-Neutral Measure:** Under the physical measure $P$, $dS/S = \mu dt + \sigma dW_t^P$. Girsanov with $\theta = (\mu - r)/\sigma$ (the market price of risk) gives $dS/S = r dt + \sigma dW_t^Q$ under $Q$. The discounted stock price $e^{-rt}S_t$ is a $Q$-martingale.

### Key Problems and Questions

- **Simple Change of Measure — Discrete:** A coin is fair under $P$ ($P(H) = P(T) = 1/2$). Define $Q$ by $Q(H) = 2/3$, $Q(T) = 1/3$. Compute $L = dQ/dP$ on each outcome. Verify $E^Q[X] = E^P[LX]$ for $X = \mathbf{1}_H$.
- **Radon-Nikodym for Normals:** $P = N(0,1)$, $Q = N(\mu, 1)$. Derive $L(x) = \exp(\mu x - \mu^2/2)$. Verify $E^P[L] = 1$. Compute $E^Q[X] = E^P[LX] = \mu$. Simulate: generate samples from $P$, reweight by $L$ to compute expectations under $Q$.
- **Girsanov — Removing Drift:** Under $P$, $X_t = \mu t + \sigma W_t^P$. Apply Girsanov with $\theta = \mu/\sigma$ to find $Q$ under which $X_t = \sigma W_t^Q$ (pure BM, no drift). Verify that the Radon-Nikodym derivative is $L_T = \exp(-\frac{\mu}{\sigma}W_T^P - \frac{\mu^2}{2\sigma^2}T)$.
- **Girsanov — Risk-Neutral Pricing of GBM:** Under $P$, $dS/S = \mu dt + \sigma dW^P$. Apply Girsanov with $\theta = (\mu - r)/\sigma$. Show $dS/S = r dt + \sigma dW^Q$ under $Q$. Verify $e^{-rt}S_t$ is a $Q$-martingale. Price a European call as $C = E^Q[e^{-rT}(S_T - K)^+]$.
- **Girsanov — Importance Sampling:** To price a deep OTM option, standard Monte Carlo under $Q$ is inefficient. Apply a second change of measure to shift the drift toward the strike. Implement and show the variance reduction vs. standard Monte Carlo.
- **Exponential Martingale:** Show $L_t = \exp(\theta W_t - \frac{1}{2}\theta^2 t)$ is a $P$-martingale. Use it to compute $P(\tau_a < T)$ for BM hitting level $a$ by time $T$: change to a measure where BM has drift $\theta$ and $L_T$ adjusts the probabilities.
- **Cameron-Martin Theorem:** A shifted BM $W_t + h(t)$ with $h \in L^2[0,T]$ is absolutely continuous w.r.t. standard BM. The Radon-Nikodym derivative is $L = \exp(\int_0^T h'(t) dW_t - \frac{1}{2}\int_0^T (h'(t))^2 dt)$. Verify for $h(t) = \mu t$ (constant drift).
- **Esscher Transform:** For a random variable $X$ with MGF $M(\theta)$, the Esscher-transformed density is $f_\theta(x) = e^{\theta x} f(x) / M(\theta)$. Show this is a change of measure. Apply to pricing under jump-diffusion models where the market is incomplete and the Esscher transform selects a specific risk-neutral measure.
- **Multi-Dimensional Girsanov:** For a $d$-dimensional BM $W_t$ under $P$, changing to $Q$ with $\theta_t \in \mathbb{R}^d$ gives $\tilde{W}_t = W_t + \int_0^t \theta_s ds$ as a $Q$-BM. Apply to a 2-asset Black-Scholes model. Show both assets become risk-neutral drifted under the same $Q$.
- **Novikov Failure — Local Martingale vs. True Martingale:** Construct an example where $L_t = \mathcal{E}(\theta \cdot W)_t$ is a local martingale but $E[L_T] < 1$ (strict local martingale). This means $Q$ is not a probability measure. Discuss implications for pricing: "bubbles" in financial models correspond to strict local martingales.

## 4. Fundamental Theorems of Asset Pricing

### Core Concepts

- **First Fundamental Theorem (1st FTAP):** A market is arbitrage-free if and only if there exists an equivalent martingale measure (EMM) $Q \sim P$ under which discounted asset prices are martingales. No-arbitrage ↔ existence of $Q$.
- **Second Fundamental Theorem (2nd FTAP):** A market is complete (every contingent claim can be replicated) if and only if the EMM is unique. Completeness ↔ uniqueness of $Q$.
- **Incomplete Markets:** When $Q$ is not unique, there is a range of no-arbitrage prices for non-replicable claims. The "price" is any expectation $E^Q[e^{-rT}g(S_T)]$ for some $Q$ in the set of EMMs.
- **Numeraire Change:** Instead of discounting by the risk-free rate, discount by any positive traded asset $N_t$. The $N$-normalized prices are martingales under the $N$-forward measure $Q^N$. Key application: the forward measure for pricing bond options.
- **Self-Financing Strategy:** A portfolio $(\theta_t^0, \theta_t^1)$ (bond + stock) is self-financing if $dV_t = \theta_t^0 dB_t + \theta_t^1 dS_t$ (no cash injections/withdrawals). Replicating strategies must be self-financing.

### Key Problems and Questions

- **1st FTAP — One-Period Model:** A stock is $\$100$ today. Tomorrow it is $\$110$ or $\$90$. Risk-free rate $r = 5\%$. Find the risk-neutral probability $q$. Show that if $q \in (0,1)$, no arbitrage exists. What if $r = 15\%$ (stock always underperforms)? Show arbitrage exists and no EMM exists.
- **1st FTAP — Trinomial Model:** A stock goes up ($\times 1.2$), stays ($\times 1.0$), or down ($\times 0.8$). $r = 5\%$. Find the set of risk-neutral probabilities $(q_u, q_m, q_d)$ with $q_u, q_m, q_d > 0$ and $q_u \times 1.2 + q_m \times 1.0 + q_d \times 0.8 = 1.05$. Show there are infinitely many. The market is incomplete (2 states of nature but only 1 risky asset + 1 bond = 2 instruments).
- **2nd FTAP — Completeness Check:** In the binomial model (2 states, 2 instruments), the EMM is unique → market is complete. In the trinomial model (3 states, 2 instruments), the EMM is not unique → incomplete. Add a second traded asset: does the market become complete? Under what conditions?
- **Replicating Portfolio — European Call:** In a one-period binomial model, find the portfolio $(\theta^0, \theta^1)$ that replicates the call payoff. Solve the linear system. Verify the cost equals the risk-neutral price $e^{-r}E^Q[\text{payoff}]$.
- **Arbitrage Detection:** Given three Arrow-Debreu securities with prices $(p_1, p_2, p_3)$ and states with payoffs matrix $D$, check for arbitrage: (a) do the state prices $\psi = D^{-1}p$ exist? (b) are they all positive? If any $\psi_i \le 0$, construct the arbitrage portfolio.
- **Numeraire Change — Forward Measure:** Price a European call on a bond using the $T$-forward measure. Show the forward price $F(t,T) = S_t / P(t,T)$ is a martingale under $Q^T$. Derive the Black formula for caplets/swaptions as a consequence.
- **Incomplete Market — Bounds on Option Prices:** In the trinomial model, compute the range $[\underline{V}, \overline{V}]$ of no-arbitrage prices for a European call by optimizing over all EMMs. Show the range narrows as you add more traded assets.
- **Self-Financing Check:** Given a portfolio strategy $\theta_t^1 = \Delta(t, S_t)$ (delta hedging), verify it is self-financing by checking $dV_t = \theta_t^0 dB_t + \theta_t^1 dS_t$. Show the accumulated hedging error in discrete time and its convergence to zero as the rebalancing frequency increases.
- **Fundamental Theorem in Continuous Time:** State the Harrison-Kreps/Harrison-Pliska version: in a continuous-time model with a finite number of Brownian motions, the market is complete iff the number of independent risky assets equals the number of Brownian motions. Apply to the Black-Scholes model (1 BM, 1 stock → complete) and Heston model (2 BMs, 1 stock → incomplete without volatility trading).
- **FTAP and Bubbles:** A strictly positive price process $S_t$ with $E^Q[e^{-rT}S_T] < S_0$ is a "bubble" — the discounted price is a strict local martingale, not a true martingale. Construct a simple example. Discuss implications: put-call parity can fail, and the fundamental price is below the market price.

## 5. Convergence of Random Variables & Limit Theorems

### Core Concepts

- **Almost Sure (a.s.) Convergence:** $X_n \xrightarrow{a.s.} X$ if $P(\lim X_n = X) = 1$. The strongest common mode of convergence.
- **Convergence in Probability:** $X_n \xrightarrow{P} X$ if $P(|X_n - X| > \epsilon) \to 0$ for all $\epsilon > 0$. Weaker than a.s. convergence.
- **Convergence in Distribution:** $X_n \xrightarrow{d} X$ if $F_{X_n}(x) \to F_X(x)$ at all continuity points of $F_X$. The weakest mode. Does not require the r.v.s to be on the same probability space.
- **Convergence in $L^p$:** $X_n \xrightarrow{L^p} X$ if $E[|X_n - X|^p] \to 0$.
- **Relationships:** $L^p \Rightarrow$ Probability $\Rightarrow$ Distribution. A.s. $\Rightarrow$ Probability. None of the converses hold in general (without additional conditions like uniform integrability).
- **Law of Large Numbers (LLN):**
  - *Weak LLN:* $\bar{X}_n \xrightarrow{P} \mu$.
  - *Strong LLN:* $\bar{X}_n \xrightarrow{a.s.} \mu$.
- **Central Limit Theorem (CLT):** $\sqrt{n}(\bar{X}_n - \mu) / \sigma \xrightarrow{d} N(0,1)$.

### Key Problems and Questions

- **SLLN — Monte Carlo Convergence:** Simulate $N$ i.i.d. samples from $\text{Exp}(1)$ and compute $\bar{X}_N$. Plot $\bar{X}_N$ vs. $N$ for $N = 1, \ldots, 10^5$. Show a.s. convergence to $\mu = 1$. Overlay the theoretical $\pm 2/\sqrt{N}$ confidence band (CLT).
- **CLT — Sum of Uniforms:** Sum $n$ i.i.d. $\text{Uniform}(0,1)$ r.v.s. Standardize: $Z_n = (\sum X_i - n/2) / \sqrt{n/12}$. Plot the histogram of $Z_n$ for $n = 1, 5, 30, 100$. Overlay the standard normal. Show the CLT convergence visually.
- **CLT — Berry-Esseen Bound:** The CLT convergence rate is $O(1/\sqrt{n})$ (Berry-Esseen theorem): $\sup_x |P(Z_n \le x) - \Phi(x)| \le C \cdot E[|X|^3] / (\sigma^3 \sqrt{n})$. Estimate $C$ numerically for Bernoulli and exponential distributions. For which distributions is the CLT approximation best/worst at small $n$?
- **Convergence in Probability but Not A.S.:** Construct the "typewriter sequence": on $[0,1]$, define $X_n = \mathbf{1}_{[k/2^m, (k+1)/2^m]}$ cycling through sub-intervals. Show $X_n \xrightarrow{P} 0$ but $X_n$ does not converge a.s. (every point is covered infinitely often).
- **A.S. Convergence but Not $L^1$:** $X_n = n \cdot \mathbf{1}_{[0, 1/n]}$ on $[0,1]$. Show $X_n \to 0$ a.s. but $E[X_n] = 1$ for all $n$, so $X_n \not\to 0$ in $L^1$. The missing condition is uniform integrability.
- **Uniform Integrability Bridges the Gap:** Show that $X_n \xrightarrow{P} X$ and $\{X_n\}$ UI together imply $X_n \xrightarrow{L^1} X$. Apply to martingale convergence: a UI martingale converges in $L^1$ (not just a.s.).
- **Slutsky's Theorem — Combining Convergences:** If $X_n \xrightarrow{d} X$ and $Y_n \xrightarrow{P} c$ (a constant), then $X_n + Y_n \xrightarrow{d} X + c$ and $X_n Y_n \xrightarrow{d} cX$. Apply to prove that the $t$-statistic converges to $N(0,1)$ as $n \to \infty$.
- **Delta Method:** If $\sqrt{n}(\hat{\theta}_n - \theta) \xrightarrow{d} N(0, \sigma^2)$ and $g$ is differentiable with $g'(\theta) \neq 0$, then $\sqrt{n}(g(\hat{\theta}_n) - g(\theta)) \xrightarrow{d} N(0, \sigma^2 [g'(\theta)]^2)$. Apply to the Sharpe ratio: $\hat{S} = \hat{\mu}/\hat{\sigma}$. Derive the asymptotic variance of $\hat{S}$.
- **Lindeberg CLT — Non-Identically Distributed Summands:** The CLT extends to independent (but not identically distributed) r.v.s if the Lindeberg condition holds. State the condition. Apply to a portfolio return as a weighted sum of non-identically distributed asset returns.
- **Multivariate CLT — Portfolio VaR:** For a portfolio of $d$ assets, the vector of sample means $\bar{R}_n$ satisfies $\sqrt{n}(\bar{R}_n - \mu) \xrightarrow{d} N(0, \Sigma)$. Use this to derive the asymptotic distribution of the portfolio mean return. Compute a CLT-based confidence interval for portfolio VaR.
