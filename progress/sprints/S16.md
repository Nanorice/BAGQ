### Calculus

**Q1 (numerical).** Solve `dy/dx = 3y`, `y(0) = 2`. Then solve `dx/dt = 5(20 − x)`, `x(0) = 0`,
and state what `x(t)` converges to as `t → ∞` and why.

**Q2 (conceptual).** You are given a Lagrangian `L = f(x,y) − λ(g(x,y) − c)` and told `λ = 4` at
the optimum. In one sentence, what does `λ = 4` tell a portfolio manager about tightening the
constraint `c` by one unit?

**Q3 (twist).** A bond's value satisfies `dV/dt = r·V` with **`r` now a function of time,
`r(t) = 0.03 + 0.01t`**. Write `V(t)` in terms of `V₀`. What breaks if you naively use the
constant-rate formula `V₀e^{rt}` here instead?

<details>
<summary>Answers — calculus</summary>

**Q1.** `y = 2e^{3x}` (separate, integrate, apply `y(0)=2`). Second: separable →
`x(t) = 20(1 − e^{−5t})`, converges to **20** because the ODE is the mean-reverting form
`dx/dt = κ(θ−x)` with `κ=5, θ=20`. It converges regardless of the starting point, because the
`e^{−κt}` decay term vanishes for any `κ>0`.

**Q2.** `λ` is the shadow price: loosening the constraint by one unit improves the objective by
≈4 (to first order). For a PM: relaxing a risk/budget constraint by one unit buys ≈4 units of
the objective (e.g. expected return) — the marginal value of the constraint.

**Q3.** `dV/V = r(t)dt` → `V(t) = V₀ exp(∫₀ᵗ r(s)ds) = V₀ exp(0.03t + 0.005t²)`. The constant-rate
formula `V₀e^{rt}` **understates** growth for large `t` because it ignores that the rate itself is
rising — using it would systematically misprice anything with a time-varying discount or growth
rate, e.g. a steepening yield curve.

</details>

### Linear algebra

**Q1 (numerical).** Find the eigenvalues and eigenvectors of `A = [[3,1],[1,3]]` by hand.

**Q2 (conceptual).** State two different ways to check whether a symmetric matrix is positive
semi-definite (not the same two you'd give for positive *definite*). Why does the distinction
between the two matter for a "leading minors" test specifically?

**Q3 (twist).** `Σ = [[0.09, −0.05], [−0.05, 0.09]]`. Is this a valid covariance matrix? Show it
two ways — eigenvalues, and the `xᵀΣx` definition with a specific `x`.

<details>
<summary>Answers — linear algebra</summary>

**Q1.** `tr=6, det=8` → `λ²−6λ+8=0` → **λ = 2, 4**. For `λ=4`: `(A−4I)=[[-1,1],[1,-1]]` →
`v=(1,1)`. For `λ=2`: `[[1,1],[1,1]]` → `v=(1,−1)`. Orthogonal, as guaranteed for symmetric `A`.

**Q2.** (i) all eigenvalues `≥ 0`, (ii) `xᵀAx ≥ 0` for all `x`, (iii) `A = BᵀB` for some `B` — any
two of these. **Leading-minors** (Sylvester) only tests positive *definite*; PSD needs **all**
principal minors `≥ 0`, not just the leading ones. A matrix can pass the leading-minor test and
still fail PSD if a non-leading principal minor is negative.

**Q3.** Eigenvalues: `tr=0.18, det=0.0081−0.0025=0.0056` → `λ²−0.18λ+0.0056=0` →
`λ=(0.18±√(0.0324−0.0224))/2=(0.18±0.1)/2` → **λ = 0.14, 0.04** — both `≥0`, so **valid PSD**.
Check via `xᵀΣx`: take `x=(1,1)`: `0.09−0.05−0.05+0.09 = 0.08 ≥ 0` ✓. A negative off-diagonal just
means the two assets are negatively correlated — still a perfectly valid covariance matrix.

</details>

### Discrete distributions

**Q1 (conceptual).** Explain in one or two sentences why `Var(X) = np(1-p)` for a Binomial
*requires* independence of the underlying Bernoullis, while `E[X] = np` does not.

**Q2 (conceptual).** State what it means for the geometric distribution to be memoryless, and
give one example of a trading scenario where assuming memorylessness would be wrong.

**Q3 (numerical).** `X ~ Geometric(p)` with `p = 0.25`. Find `E[X]` and `P(X > 4)`.

**Q4 (numerical).** Orders arrive at a venue at a Poisson rate of 6 per minute. Find
`P(exactly 2 orders in the next 10 seconds)`.

**Q5 (twist).** You flip a fair coin repeatedly. What is the expected number of flips until you
see the pattern **`HTH`**? (Not `HH` — a new pattern. Set up states and use first-step
conditioning.)

<details>
<summary>Answers — discrete distributions</summary>

**Q1.** `E[X]=E[ΣXᵢ]=ΣE[Xᵢ]` by linearity, which holds for *any* dependence structure. But
`Var(ΣXᵢ) = ΣVar(Xᵢ) + 2Σᵢ<ⱼCov(Xᵢ,Xⱼ)` — the cross terms vanish only under independence, which is
what collapses it to `ΣVar(Xᵢ) = np(1−p)`.

**Q2.** `P(X>m+n | X>n) = P(X>m)` — having already failed `n` times tells you nothing about how
many more trials remain; the distribution of remaining trials resets. Wrong example: modelling
time-to-next-large-order as memoryless when order flow is actually **clustered** — one big order
raises the near-term probability of another, a Hawkes-type process rather than a memoryless one.

**Q3.** `E[X] = 1/p = 4`. `P(X>4) = (1−p)^4 = 0.75^4 ≈ **0.3164**`.

**Q4.** Window = 10s = 1/6 min, so `λ' = 6 × 1/6 = 1`. `P(X=2) = e^{-1}·1²/2! = **e^{-1}/2 ≈ 0.184**`.

**Q5.** States by longest current suffix matching a prefix of `HTH`: `S0` (nothing useful),
`S_H` (have "H"), `S_HT` (have "HT"). From `S0`: `H→S_H`, `T→S0`. From `S_H`: `H→S_H` (still just
"H"), `T→S_HT`. From `S_HT`: `H→done`, `T→S0` — the `T` breaks the whole pattern, back to start,
**not** to `S_H`, because `HTH`'s tail doesn't overlap its own prefix past nothing.
`E0 = 1 + ½E_H + ½E0` → `E0 = 2 + E_H`.
`E_H = 1 + ½E_H + ½E_HT` → `½E_H = 1 + ½E_HT` → `E_H = 2 + E_HT`.
`E_HT = 1 + ½(0) + ½E0` → `E_HT = 1 + ½E0`.
Substitute up: `E_H = 2 + 1 + ½E0 = 3 + ½E0`. Then `E0 = 2 + 3 + ½E0` → `½E0 = 5` → **`E0 = 10`**.

</details>

### Continuous distributions

**Q1 (conceptual).** State the tail formula for `E[X]` of a non-negative random variable, and
explain in one sentence why it's often faster than integration by parts.

**Q2 (conceptual).** Explain the exact equivalence between "constant hazard rate" and
"memoryless" — why does one imply the other?

**Q3 (numerical).** `X ~ Exp(λ)` with `λ = 0.5`. Find `E[X]`, `Var(X)`, and `P(X > 6)`.

**Q4 (numerical).** `Z ~ N(0,1)`. Compute `P(Z < -1.96)` and `P(0 < Z < 1)` using the 68/95/99.7
anchors. Approximate is fine — show your reasoning.

**Q5 (twist).** Two independent servers process requests with exponential service times,
`Exp(λ₁=2/min)` and `Exp(λ₂=3/min)`. What's the probability server 1 finishes first, and what is
the distribution of "time until *some* server finishes"? Now: if you instead needed the time
until **both** have finished, would the exponential machinery still apply directly? Why not?

<details>
<summary>Answers — continuous distributions</summary>

**Q1.** `E[X] = ∫₀^∞ P(X>x)dx`. Faster because it needs only the survival function, no
integration-by-parts bookkeeping — e.g. for `Exp(λ)` it's a one-line integral of `e^{-λx}` versus
by-parts with a boundary term.

**Q2.** `h(x) = f(x)/(1-F(x))` constant means the instantaneous failure rate never depends on how
long you've already survived — which is exactly the statement that the *remaining*-life
distribution doesn't depend on elapsed time (memorylessness). They're the same fact in two
languages: hazard rate is a rate description, memorylessness is a conditional-probability
description of the identical property, and both uniquely characterise the exponential among
continuous distributions.

**Q3.** `E[X] = 1/λ = **2**`. `Var(X) = 1/λ² = **4**`. `P(X>6) = e^{-0.5·6} = e^{-3} ≈ **0.0498**`.

**Q4.** `P(Z<-1.96) ≈ **0.025**` — half of the 5% outside `±1.96`, the 95% two-tail boundary.
`P(0<Z<1) ≈ **0.34**` — half of the 68% within `±1σ`, since the normal is symmetric about 0.

**Q5.** `P(server 1 first) = λ₁/(λ₁+λ₂) = 2/5 = **0.4**`. Time until *some* server finishes =
`min(X,Y) ~ Exp(λ₁+λ₂) = Exp(5)`. For **both** finished, that's `max(X,Y)`, not `min` — the
memoryless/rates-add shortcut applies to the *minimum* of independent exponentials, not the
maximum. `max(X,Y)` is **not exponential**: its hazard rate isn't constant, because waiting on
whichever is slower means conditioning on survival of both, which changes the shape. Compute it
directly instead: `P(max≤t) = P(X≤t)P(Y≤t) = (1-e^{-λ₁t})(1-e^{-λ₂t})`.

</details>
